# Marca — Nikkiro Audio Visualizer

- **Colores**: blanco perla `#EAF0F7`, negro `#0A0B0E`. Único acento permitido si algún día se necesita: azul aura `#8fd0ff`.
- **Espacio libre mínimo**: un radio del aro por cada lado.
- **Tipografía**: Cinzel 700 (nombre) + Space Mono (descriptor). No añadir una tercera.
- **Prohibido**: rotar el aro, aplicarle sombra, rellenarlo, o teñirlo con las 22 paletas del visualizador — esas paletas son del render, no de la marca.

## Qué archivo usar

| Archivo | Uso |
|---|---|
| `icon.svg` | Iconos de app y favicon |
| `mark.svg` | Sobre fondos oscuros |
| `mark-inverse.svg` | Sobre fondos claros |
| `lockup.svg` | README y landing |

`lockup.svg` es el único archivo con su propia placa de fondo (`#0A0B0E`, esquinas redondeadas) — a diferencia de los demás, que asumen que ya están sobre una superficie oscura, este va incrustado directo en el README y tiene que leerse igual en el tema claro y el oscuro de GitHub.
